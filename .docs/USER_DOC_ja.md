 # ユーザー向け説明

## 概要
これは、Docker、Nginx、WordPress、MariaDB を使用したウェブサイト開発ツールです。

## 起動方法と停止方法
- リポジトリ直下のディレクトリで「make」コマンドを実行してください。これにより、各Dockerコンテナが起動します。
- プロセスを停止するには、Git の直下のフォルダで「make down」を実行してください。これにより、作成されたすべてのコンテナが削除されます。

## 利用できるページ
- https://mmachida.42.fr:443 にアクセスしてください。ブラウザにWordPressのダッシュボードが表示されます。
    - プロフィール編集...パスワードやメールアドレス・ニックネームなどを編集できます
    - 記事の投稿...権限がある場合のみ投稿・編集できます
    - メディアのアップロード...権限がある場合のみアップロードできます
    - コメントの閲覧

- 管理者ページには https://mmachida.42.fr:443/wp-admin/ でアクセスすることができます。 
    - ダッシュボード...新着情報を確認できます
    - 更新...wordpress本体、テーマ、プラグインなどの更新情報の確認や操作ができます
    - 投稿...記事を作成・編集・公開することができます
    - メディア...画像などのファイルを管理できます
    - コメント...コメントを管理できます
    - 外観...デザインテンプレートをインストールしたり編集したりすることができます
    - プラグイン... 拡張機能を管理できます
    - ツール...各種データをインポートしたりエクスポートしたりすることができます

## 認証情報
ログイン時のパスワードはsecretsフォルダの配下をご参照ください
credentials.txtにはWordpressユーザのパスワードが記載されています
- WP_ADMIN_PASS...Wordpress管理者
- WP_PASS...Wordpress 書き込み用ユーザ
